# 用户自备表情包

仓库不附带图片、GIF或下载脚本。没有素材时，机器人正常回复文字。

1. 将你有权使用的 PNG/JPG/GIF/WebP 放入此目录，可创建 `炸毛`、`委屈`、`害羞`、`疑问`、`开心` 等子目录。
2. 用描述图意的文件名，例如 `委屈/不许凶我.gif`、`炸毛/本喵生气了.png`。
3. 运行 `python import_stickers.py`，或在控制台点“导入表情包”。
4. 图片、索引及使用记录均保留本地。添加/删除图片后重新导入，下次回复自动读取新索引。

每张图片最多1.5MB，边长20～2500像素。GIF保留原动画。相同内容只索引一次；损坏、超大文件和目录外链接会跳过。

模型根据文件名、情绪标签选择图片ID，不读取图片像素。API只收到候选描述；被选图片通过你的OneBot客户端发送到群。文件名请勿包含私人信息。

每轮最多一张图，通常每群图片间隔12秒；明确要求发表情包时可跳过冷却。最近18张优先避开。明确说“不要发表情包，只发文字”时不选图；要求GIF时优先选动图。

本目录除这份说明外均被 Git 忽略，不要强制加入素材或自动生成的 catalog.json。
